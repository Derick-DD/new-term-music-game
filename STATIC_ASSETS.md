# Static asset inventory

This inventory follows the Activity H5 Builder resource rules used by the
online deployment. Runtime assets are split between versioned local files and
approved QQ Music CDN dependencies.

## Local assets required by the current campus release

- `public/activity-bridge.js` — Activity API compatibility and invocation bridge.
- `public/activity-sites.config.js` — online activity configuration.
- `public/assets/campus-season/` — all current campus game, tutorial, result,
  share, and QR artwork.
- `public/assets/ui/play-icon.png` — local playback control fallback icon.
- `public/audio/congratulations-treasure-tf-family.mp3` — permitted local audio
  fallback when official song playback is unavailable.
- `app/data/congratulations-treasure.chart.json` — song duration and rhythm
  timing data bundled into the application.
- `public/og-sites.png` — online social preview image.

These files are source-controlled and are included in the standalone static
asset archive.

## Approved remote runtime dependencies

The following dependencies remain loaded from the official QQ Music CDN and
are not copied into the repository or static asset archive:

- `https://y.qq.com/lib/commercial/h5/polyfill.min.js`
- `https://y.qq.com/lib/commercial/h5/music-2.4.0.min.js`
- `https://y.qq.com/component/m/fixTopBar/dist/fixTopBar.js`
- `https://y.qq.com/component/m/qmfe-unity-ad/iife/index.js`

## Preserved legacy resources

The existing `earth-tour`, `lueluelue`, `og.png`, and default SVG resources
remain in Git so older implementations are not destroyed. They are not used by
the current campus game flow and are intentionally excluded from the standalone
current-release asset archive.

## Generated output

`dist/` is generated by the Sites build/package process. It is intentionally
ignored by Git because the deploy archive is rebuilt from the versioned source
and local assets for every release.
